# 垃圾清理

从标题栏“垃圾清理”进入独立页面。空间探测正在运行时需先停止；返回后保留已有空间探测结果。页面复用 SiaWebUI Button、Card、Checkbox、Modal、Table、Spin、Tag 和列宽拖拽插件。

## 清理范围

- 临时文件：当前账户 LocalAppData/Temp 与 Windows/Temp，默认勾选可清理项。
- 崩溃转储和错误报告：当前账户 CrashDumps、Microsoft/Windows/WER，以及 ProgramData 下 WER 的 ReportArchive、ReportQueue，默认不选。
- 上述两类仅处理超过 7 天未修改的文件，不删除目录本身；未来时间戳保留。
- 缩略图：仅 Explorer 目录直属的 `thumbcache_*.db`，默认不选，系统随后按需重建。
- 回收站：Windows Shell 当前账户所有磁盘的汇总，不逐项列出或勾选。默认不选，额外确认后整体永久清空。调用系统清空期间不能中断；确认后到系统清空之间加入回收站的内容也可能被清空。

不遍历微信资料、下载目录、浏览器资料或包管理器缓存。没有自动、计划或后台静默删除。

## 保护与限制

扫描和清理在后台线程执行，前端每 400ms 查询轻量进度。扫描上限为 20,000 条明细或待扫描路径；达到上限、取消时明确标记部分结果，未发现条目不会被清理。

文件删除只接受后台本次扫描计划编号和条目 ID，不接受前端路径。计划执行前消耗，不可重复使用。删除前锁定父路径目录，拒绝重解析点和链接，通过独占句柄校验卷、文件 ID、大小、修改时间、硬链接数及保留期限，再通过同一句柄删除。被占用、无权限、发生变化或不存在的文件会保留并报告原因。不提升目录权限，不接管所有权，不结束其他进程。

删除为永久操作，不移入回收站。停止不会撤销已经完成的删除。回收站由系统接口执行；清空前重新比较汇总，变化则跳过。磁盘空间实测显示本地卷前后可用空间净变化，同时单独展示已清理文件逻辑大小，二者不可等同（其他进程、压缩和稀疏文件均会影响结果）。

## 验证

`cargo test --release -j 1 --manifest-path apps/disk-space/src-tauri/Cargo.toml --lib cleanup::tests`

测试只创建唯一临时测试目录及测试文件，验证文件被占用/变化时拒绝删除以及未变化文件的句柄删除，不清理真实系统临时文件，不清空回收站。
