# 弹框遮罩动画与层级

<!-- 记录框架层的动画约束，避免业务页面重复覆盖遮罩样式。 -->

Modal 的遮罩由根节点的 `::before` 绘制，使用透明度动画，与弹窗内容同时挂载、同时退出，时长均为 220ms。遮罩不再对背景色执行逐帧动画，减少页面主线程繁忙时背景重绘落后于弹窗合成动画的问题。

根节点建立独立层叠上下文，遮罩层级为 0，弹窗内容层级为 1。外部 `zIndex` 仍控制整个弹框的层级，业务不需要单独设置遮罩层级。减少动态效果模式同时关闭遮罩与内容动画。遮罩点击关闭和 `afterOpenChange` 回调保持原有行为。

浏览器回归入口为 `apps/docs/tests/modal-motion.html`，运行文档服务（端口 4189）后执行 `node scripts/test-modal-motion.cjs`；可通过第一个参数指定 Playwright 模块路径。覆盖遮罩透明度关键帧、嵌套弹框点击命中、连续开关、退出过程中重新打开、遮罩关闭及减少动态效果。

上述检查保证框架自己的遮罩位于内容下方。业务自定义 `zIndex`、独立挂载容器产生的外部层叠上下文仍需在实际页面验证，不能据此宣称所有偶发遮挡均已复现或解决。
