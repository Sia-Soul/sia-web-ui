# 组件动效规范与检查记录

检查日期：2026-10-30。范围为属性样例索引的全部 154 个组件入口，加上 message、notification、自动 title 和共享 Portal。检查方式是源码与样式逐类核对，共享时间轴及关键显隐入口另做真实浏览器回归；不把源码覆盖表述为每个组件都已逐一人工观看。

## 固定规则

1. 同一组件的完整入场、完整退场原则上使用相同时长；唯一例外是面板关闭：保留弹性入场，关闭取消回弹并缩短时长。
2. 下拉面板以 260ms 弹性回弹流出，关闭以 140ms 缩小淡出，无额外回弹；Modal、Drawer 关闭直接回到入场起点。其他提示及淡入淡出继续共用关键帧等时长反播。
3. 下拉面板中途反向只保存当前 transform 与 opacity，再从当前画面连续到新目标，按剩余缩放与位移距离缩短时长。Modal、Drawer 中途反向只采样一次当前 transform、opacity 和遮罩透明度。其他提示保留原时间轴位置。
4. 退场完成前保留节点并阻止交互。业务回调立即执行，完成回调等待真实动画结束。父组件直接卸载组件或清空 children 时，框架无法保留外部移除的内容。
5. 下拉面板使用框架小浮层的果冻缩放与渐显渐隐，不复制录像的外形、重复帧或模糊效果。WAAPI 连续插值 transform 与 opacity；不动画 clip-path、filter、圆角、边框或阴影，不逐帧读取布局或 setState，实际帧率依赖设备。
6. 减少动态效果模式直接切换。静态结构不强制动画；加载、数据变化和游戏时间轴没有成对入退场语义，按各自职责处理。

## 本次修正及完整时长

| 类型 | 入场 / 退场 | 处理 |
| --- | --- | --- |
| 选择器、Dropdown、Menu 弹出子目录、FloatButton.Group 菜单、自动 title | 260 / 140ms | 缩放淡入、弹大回收后归位，关闭直接缩小淡出，保留原有面板外观 |
| Drawer | 320 / 180ms | 打开弹性滑入，关闭直接滑出，遮罩同步 |
| Modal、GameDialog | 240 / 160ms | 打开弹性入场，关闭无回弹缩小淡出，遮罩同步 |
| Tooltip、Popover、Popconfirm、message、notification | 280 / 280ms | 同轨迹反播；message 正文仅位移、背景单独缩放 |
| Alert、Spin、Tour、ImagePreview、FloatingPanel、FloatButton.BackTop | 180 / 180ms | 补齐淡入/反向淡出与退场保留 |
| Menu 内嵌目录、Collapse | 220 / 220ms | 保留双向布局过渡 |
| 浮动滚动条 | 150 / 150ms | 保留双向透明度过渡 |
| QueryForm 查询条件 | 240 / 240ms | 字段淡入淡出、操作区位移和外层高度同步过渡 |

- Alert 的 onClose 立即执行，afterClose 改为真实淡出并移除之后执行；父组件提前卸载时不再补发完成回调。
- 清理 22 个未引用的旧弹层关键帧及被覆盖的动画声明，避免保留两套不一致的实现。
- 自动 title 提示按 Document 共享一个服务与提示层；热更新或加载多个框架副本不会重复安装全局监听、叠加背景和阴影。每个独立文档仍单独管理自己的提示。
- 补齐 Steps、Calendar、Tree 的 140ms 状态颜色反馈，并修正部分减少动态效果规则被后续样式覆盖的问题。
- Button 点击 320ms、Menu 选中背景 260ms、Tabs 拉伸指示器 300ms 属于交互反馈，不是弹层入场/退场。保留原有快速连续操作支持。
- Checkbox、Radio 普通形态点击使用 360ms 图形等比缩放回弹，描边 Radio.Button 使用 320ms、0.92～1.08 倍回弹。实心按钮分组使用单个背景层，280ms 内以液体沙漏形变经过细颈流入目标项；两向共用阶段及时长，连续切换从当前几何接续，文字不缩放。值和回调立即更新，禁用时不触发。
- Segmented 横向、纵向使用单个背景层，以 260ms 位移和缩放衔接选项；首次定位与尺寸变化直接对齐，锯齿形双选项保留自身样式。
- QueryForm 的字段和操作区只动画 transform/opacity，外层高度过渡让后续内容自然跟随。退出字段立即 inert，结束后隐藏并保留表单值；最多 24 个字段加操作区参与独立动画。自适应测量在过渡期间暂停，结束后补测一次，不逐帧提交 React 更新。

## 回归证据

- `scripts/test-motion-consistency.cjs`：13 组共享轨迹（四向下拉、四向 Drawer、Modal、Tooltip、notification、message、fade），检查下拉面板只动画合成属性且不覆盖最终外观，检查 Modal/Drawer 快速无回弹退场和其他提示等时长反播，核对快速双向折返及减少动态效果。真实入口覆盖悬浮菜单、图片预览、Spin、Tour、FloatingPanel、Alert 和自动 title。
- `scripts/test-overlay-motion.cjs`：真实 Select、Dropdown、多级菜单、消息/通知、Drawer/Modal 的开合、延后内容、关闭骨架、焦点及中断回归。
- `scripts/test-title-tooltip.cjs`：同页多个框架副本的 Badge/Button 悬停只显示一层自动提示，退出动画后完整移除。
- `scripts/test-radio-selection.cjs`：实心 Radio 液体沙漏轮廓与细颈几何、双向时长、快速折返、不等宽选项、键盘切换、禁用、子项圆角和减少动态效果。
- Button、Menu 专项浏览器回归；API 注释检查、组件构建、发布悬停提示检查、文档类型检查、属性样例覆盖检查。
- `scripts/test-control-motion.cjs`：Checkbox/Radio 鼠标与键盘反馈、禁用状态、Segmented 横向/纵向/快速折返、QueryForm 连续开合、隐藏值保留、减少动态效果和性能采样。包含 12 个查询字段、1,200 行普通内容的 Edge 无头浏览器最终测试中，一次展开加收起采集 75 帧，帧间隔中位数约 8.3ms、95 分位约 8.5ms，未记录到超过 50ms 的长任务；React Profiler 记录 6 次提交。该短时采样用于检查实现开销，不等同于所有设备或复杂业务页面的帧率保证。

此检查验证动效与生命周期，不承诺固定帧率。实际帧率仍受设备、浏览器和业务主线程负载影响。

- `scripts/test-popup-style-motion.cjs`：深浅主题下以静态 CSS 为基准验证开合全过程的圆角、边框、阴影与背景不变；记录真实 15 项列表和 1000 项虚拟列表各 5 次开合的帧间隔与长任务，不将 rAF 采样等同于所有设备的实际合成 FPS。

- 浮动滚动条针对 fixed Portal 的挂载、移除及内部变化进行局部发现，Select 仅切换 is-open 时检查控件子树及祖先；背景布局变化仍保留全量检查。轨道增删不会触发其他 Provider 整页扫描，候选测量与轨道创建分批进行。
