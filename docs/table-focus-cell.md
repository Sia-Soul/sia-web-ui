# 表格单元格定位与边框提示

`await tableRef.current?.focusCell(rowKey, columnKey, options)` 使用稳定行键、叶子列键定位；业务决定目标，框架负责滚动、可见性和视觉反馈。配置类型为公开导出的 `TableCellFocusOptions`。

## 定位和播放顺序

- 横纵滚动避开固定列、吸顶表头和底部合计，支持 DOM 和 Canvas 虚拟窗口。
- 等待目标挂载、连续两帧位置稳定且整格可见，再选中聚焦并播放。不进入编辑、不修改数据或撤销历史。
- 默认从左上角顺时针增长，尾端固定；300ms 长满一圈后，头端停在终点，尾端沿同方向前进，300ms 收缩至头端后消失。正常模式不整体淡出。
- SVG 位于 body 顶层，避开祖先裁剪，高于框架固定列、浮层和浮动滚动条；鼠标穿透。目标滚出可视区、隐藏、卸载或新定位时立即清理。
- 减少动态效果偏好下仅同色完整边框 200ms 淡出，忽略速度倍率，不增长或收缩。
- 隐藏列、其它页、无效键、隐藏表格、目标不能完整显示或被新调用取代返回 false；不自动翻页或改变列显隐。成功定位返回 true，不等待动效结束。
- 在数据提交、弹框关闭动画完成后调用，避免焦点恢复干扰。

## 公开配置

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| highlight | true | false 仅定位、选中和聚焦，其它动效配置不生效 |
| color | #ff303b | CSS 颜色，同时作用于描边和轻微柔光；无效颜色回退默认值，CSS 变量需在页面根层可用 |
| speed | 1 | 速度倍率；2 为两倍速度（150ms 增长、150ms 收缩），0.5 为半速；有限正数限制在 0.1～10，非法值回退 1 |
| lineWidth | 4 | CSS px；有限正数限制在 1～12，非法值回退 4；极窄单元格按可容纳宽度缩小 |

商品导入计划使用橙色：

```tsx
// 校验与首个问题选择由业务负责，框架负责先定位后播放。
const located = await tableRef.current?.focusCell(issue.rowKey, issue.columnKey, {
  color: '#fa8c16',
  speed: 1,
  lineWidth: 4,
});
```

示例页 WorksheetDemo 已使用上述橙色配置。业务正式包发布前不修改 node_modules，不添加业务 CSS/DOM 补丁；发布后升级依赖再接入。

## 验证

浏览器回归覆盖 DOM/Canvas 500 行、固定列和真实高层遮挡、自然增长和收缩、默认红色与自定义橙色、速度倍率、线宽、无效值回退、关闭动效、重复定位、滚出可视区、减少动态效果及卸载清理。收缩中点的归一化长度为 50、偏移为 -50，头端保持在周长 100；终点长度为 0、偏移为 -100。自然采样同时验证长度下降与尾部前进，避免仅凭关键帧或截图误判。

证据：`logs/table-focus-cell/configurable-browser.log`、`configurable-build.log`、`configurable-api.log`、`configurable-hover.log`。
