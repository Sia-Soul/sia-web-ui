# 浮动滚动条的布局更新

`FloatingScrollbarProvider` 会自动发现页面中的滚动容器，也可以通过 `targetRef` 限定接管范围。
结构、类名、隐藏状态、尺寸及其他布局样式变化时重新发现容器。仅当元素宽高为明确的 px 值、采用 absolute/fixed 定位，且只改变 left/top/transform 时，按显示帧合并并仅复核其子树及祖先，同时更新已发现滚动条的位置。这样也保留 flex 兄弟尺寸变化后的新滚动区域发现能力。

这让指针预览、绝对定位元素等连续更新位置时，避免重复测量整页无关内容。子元素高度改变后，祖先开始或停止滚动仍会自动接入或移除滚动条。表格自带视口及 `data-sia-native-scrollbar` 区域继续由各自的滚动实现负责。
