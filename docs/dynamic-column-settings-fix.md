# 动态父子列表格设置修复

<!-- 本记录只描述此次 Table 修复，不代表工作区其他并行改动已经由本任务验收。 -->

## 问题

业务父列收起时为叶子列，展开时提供 children。旧列设置过滤掉不在当前叶子列表的设置，却未补齐新叶子，导致设置列表缺列、分组位置变化，以及保存时丢失另一展开状态的配置。

## 修改

- Table 内部 columnSettings.ts 根据真实树形层级投影当前设置，不依赖业务 key 的命名。
- 新子列继承父列显隐和固定位置，父列排序位置不会随展开跳到最后。
- 暂时收起的子列配置保留于快照，再次展开恢复宽度、显隐与相对顺序。
- 插件 apply、拖动列宽、每页条数保存使用同一合并逻辑，附加序号/选择列不进入设置。
- 存储快照保留 order，并同步数组排序以兼容旧适配器。
