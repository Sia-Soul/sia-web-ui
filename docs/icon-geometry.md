# 图标主体尺寸

所有 `Icon` 名称和实心变体使用同一规则：24×24 SVG 画布，图形几何边界最长边为 18 单位，中心为 (12, 12)，保持原始长宽比例。边界不包含描边。圆形直径为 18，横线宽度为 18；不能将非方形图标拉伸成 18×18。

`size` 控制外框，默认 `1em`。例如 `size={16}` 的主体最长边为 12px，`size={24}` 时为 18px。默认描边仍为画布中的 1.8 单位，随外框尺寸同比变化。内部几何归一化不会额外改变描边粗细；实心图标的反白细节保留原始描边。

`iconBounds.ts` 记录原始路径的真实 SVG 几何边界，包括曲线极值和子组变换。`iconGeometry.tsx` 在模块加载时预计算等比缩放、居中和显式描边补偿，不在挂载后测量 DOM，SSR 与浏览器首帧一致。新增图标必须补齐边界数据，更新已有路径后也需重新测量。不能直接根据路径中最大的坐标推断曲线边界。

## 全量验收

1. 启动文档站，打开 `/components/icon`，清空搜索。目录自动补齐未分类名称。
2. 运行 `node scripts/check-icon-geometry.cjs --expression`，通过浏览器工具只读执行输出表达式，并将结果保存为 JSON。
3. 运行 `node scripts/check-icon-geometry.cjs <测量结果.json>`，核对完整覆盖、主体 18 单位、居中、默认描边和原始边界数据同步。
4. 在“统一主体尺寸”示例中检查 16、24、32px 外框，检查实心反白细节、小尺寸箭头和窄图标。更新路径时，以外层归一化组的 `getBBox()` 重新获取原始边界，再更新 `iconBounds.ts`。

首次全量审计为 215 个基础图标、28 个实心变体。原始最长边约 12.34～24.07 单位，因此仅统一 `size` 或单独调整齿轮不能统一主体尺寸。
