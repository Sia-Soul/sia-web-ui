# 下拉面板动效

## 当前实现

- 打开 260ms：以靠近触发器的边缘中心为原点，从 0.88 倍缩放并淡入，弹大到横向 1.11 / 纵向 1.085 倍，再回收到 0.945 / 0.965 倍，最后恢复正常尺寸。
- 关闭 140ms：直接缩小至 0.88 倍并淡出，结束后卸载，不再安排预备下沉或重复回弹。
- 收起端向触发器轻微靠近 6px；不包含右侧固定扩张、16px 整体下沉或先下沉后上浮的轨迹。
- 使用 transform 与 opacity 合成属性；不改变面板最终圆角、边框、阴影与布局，不使用裁剪路径或虚化滤镜。
- 中途反向从当前变换和透明度接续，减少动态效果模式直接完成。
